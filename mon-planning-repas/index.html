☁️ Guide d'activation Cloudflare D1 SQL

MonPlanningRepas est désormais 100% Cloud SQL : aucune recette n'est stockée localement dans le navigateur. Suivez ces 3 étapes simples dans votre Dashboard Cloudflare pour connecter votre base de données :

1 Créer la base D1 dans Cloudflare

Dans votre Dashboard Cloudflare : allez dans Storage & Databases → D1 SQL Database → cliquez sur Create database. Nommez-la par exemple spinfoundry-db.

2 Lier la base au projet Cloudflare Pages (Variable 'DB')

Allez dans Workers & Pages → cliquez sur votre projet spinfoundry → onglet Settings → sous-menu Functions → descendez à D1 database bindings → cliquez sur Add binding :

• Variable name : DB (impérativement en MAJUSCULES)
• D1 database : sélectionnez spinfoundry-db

Cliquez sur Save pour enregistrer la liaison.

3 Créer les tables SQL (Exécuter le schéma)

4 Redéployer Cloudflare Pages

Pour que la nouvelle liaison soit activée, allez dans l'onglet Deployments de votre projet Pages et cliquez sur les 3 points du dernier déploiement → Retry deployment (ou faites simplement un git push).
