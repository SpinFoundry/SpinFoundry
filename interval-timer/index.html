Why Standard JavaScript Timers Drift in Gyms

Most web timers use setInterval() or setTimeout() on the browser's main thread. When your phone's screen dims, the tab is put in the background, or an operating system enters low-power mode, modern mobile browsers aggressively throttle main-thread timers down to once every 1–60 seconds. A 20-second sprint can easily stretch into 45 seconds of actual time.

SpinFoundry's Interval Timer executes inside an isolated inline Web Worker running on a background execution thread. The clock continuously synchronizes against monotonic timestamps (performance.now()), ensuring exact millisecond precision and absolute zero drift, even when the browser tab is hidden or minimized.

Screen Wake Lock & Zero External Assets

During active intervals, the Screen Wake Lock API automatically prevents mobile screens and laptops from falling asleep or dimming across your training floor. Audio countdown cues and start/stop bells are synthesized procedurally in client-side Web Audio API with zero external audio assets or network requests.
